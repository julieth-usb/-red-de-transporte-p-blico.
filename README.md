# Red de transporte público - Cúcuta

Este repositorio contiene una solución en Java que integra:

- representación de estaciones y rutas con grafos,
- validación de acceso con lógica proposicional,
- cálculo de probabilidades de retrasos con distribución binomial,
- comparación entre resultados teóricos y experimentales.

## Ejecutar

```bash
javac src/SistemaTransporteCucuta.java
java -cp src SistemaTransporteCucuta
```
